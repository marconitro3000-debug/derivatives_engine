> Built a modular Python derivatives engine and node-based visual workbench for Phoenix Autocall Notes, combining Monte Carlo simulation, autocall/barrier event detection, Greeks, stress testing, cashflow analytics, public market-data ingestion and JSON workflow serialization.

> Modular derivatives pricing engine with a visual workbench for structured products, Monte Carlo pricing, Greeks, stress testing and public market-data ingestion.

- prototype;
- educational;
